# Inari 存档修改器

关于游戏《Inari》的存档编辑工具，本来想做风灵月影那种实时修改，奈何没实力，ui是让d老师做的。
## 游戏介绍
Inari 是一款以日本美丽海滨小镇为背景的恋爱模拟 SLG（沙盒生活模拟）游戏。游戏的名称来源于日本神话中的稻荷神——掌管五谷丰登、商业繁荣的神明。玩家在旧仓库中发现藏宝图后重返故乡，与三位美丽女性——高岭（稻荷神社巫女）、朝美（青梅竹马）和澪（神秘女性）展开浪漫故事。游戏融合了约会模拟、沙盒探索、钓鱼农耕、料理制作等丰富玩法，并采用 Live2D 技术呈现生动的动画演出。游戏支持中文、英语、日语、韩语和俄语五种语言，全程日语配音。（哈哈哈，来自百科）
## 功能特性
我以金币区分了存档，这样你就知道你的存档分别是哪些！
- 货币资源：金钱 / 行动点 / 体力 / 技能点
- 角色好感：高岭 / 朝美 / 澪（好感度 + 性欲）
- 道具：198 种道具（中文名，可搜索，有些英文，没有中文，应该是用来占位的）
- 技能：72 个技能
- 图鉴：一键解锁全部图鉴 / 内容 （解锁图鉴要打开 gallery读取;）
- 自动备份：修改前自动备份为 `<存档>.bak`，可一键还原

## 使用方法

1. 运行程序，点击顶部「打开存档」，选择游戏根目录 `SaveDir` 文件夹内的存档
2. 改前请先退出游戏，改完重新读档

## 环境与依赖

- Python 3.8+（Windows）
- 依赖见 `requirements.txt`：`pycryptodome`、`pywebview`
