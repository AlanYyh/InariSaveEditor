# Inari 存档修改器

关于游戏《Inari》的存档编辑工具。
## 功能特性

- 货币资源：金钱 / 行动点 / 体力 / 技能点
- 角色好感：高岭 / 朝美 / 澪（好感度 + 性欲）
- 道具：198 种道具（中文名，可搜索）
- 技能：72 个技能
- 图鉴：一键解锁全部图鉴 / 内容
- 自动备份：修改前自动备份为 `<存档>.bak`，可一键还原

## 使用方法

1. 运行程序，点击顶部「打开存档」，选择游戏根目录 `SaveDir` 文件夹内的 `.json` 存档（如 `saveData01.json`）
2. 改前请先退出游戏，改完重新读档

## 环境与依赖

- Python 3.8+（Windows）
- 依赖见 `requirements.txt`：`pycryptodome`、`pywebview`
